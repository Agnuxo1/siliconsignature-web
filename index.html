🔐 How It Works
  1. Hash: SHA-256 of image structure
  2. Proof: ASIC/CPU finds nonce (PoW)
  3. Embed: Signature in PNG metadata
  4. Watermark: Reed-Solomon in LSB
  5. Verify: Check nonce + hash match
🛡️ Tamper Resistance
  • Survives 40% pixel destruction
  • Reed-Solomon error correction
  • 5× redundancy encoding
  • ASIC work unforgeable ($10K+ cost)
  • No central authority needed
