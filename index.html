About SiliconSignature

What is SiliconSignature?

SiliconSignature is a cross-platform image authentication system that embeds cryptographically signed watermarks directly into image pixels. Unlike visible watermarks or metadata-based solutions, SiliconSignature stores signature data in the least significant bits (LSB) of RGB channels, making it resilient to format conversions and basic editing.

How It Works

  1. Hash - Compute SHA-256 of the original image pixels
  2. Proof of Work - Search for a nonce such that SHA-256(SHA-256(hash || nonce)) < difficulty target
  3. Encode - Build JSON payload, apply Reed-Solomon error correction (32 parity symbols over GF(2⁸))
  4. Embed - Write LSB of RGB channels with 5x repetition for redundancy
  5. Verify - Extract LSB bits, vote across 5 repetitions, RS decode, validate signature

Technical Specifications

Field GF(2⁸) with primitive polynomial 0x11d
Error Correction 32 Reed-Solomon symbols
Repetition 5x redundancy
Hash Function SHA-256 (double)
Channels RGB LSB (3 bits per pixel)
Difficulty 0x0000FFFF...

Security Notes

This is a software simulation of ASIC-based signing. The proof-of-work uses CPU-based nonce searching with a reduced difficulty target. For production use, ASIC hardware (e.g., BM1387) provides the computational security guarantee.

LSB steganography is detectable by statistical analysis. For covert applications, additional obfuscation techniques are recommended.
